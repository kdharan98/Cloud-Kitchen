# Daily Bite customer app

Standalone React, TypeScript, Vite, Tailwind CSS, and Lucide React application.
The first frontend phase includes the welcome carousel and customer home screen,
with a local sample menu and cart. It does not include checkout, payments,
subscriptions, orders, or account screens.

From this directory, run `npm install` and `npm run dev`. The dev server uses
port 5173. Run `npm run lint` and `npm run build` for quality checks.

Set `VITE_API_BASE_URL` in a local `.env` to configure the shared backend API.
See the repository [README](../../README.md) for full setup instructions.
