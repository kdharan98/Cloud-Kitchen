# Daily Bite Admin Dashboard

Standalone React, TypeScript, Vite, Tailwind CSS, and Lucide React application.

Run `npm install` and `npm run dev` from this directory. The dev server uses
port 5174. Run `npm run build` to type-check and create a production build.

This is a UI prototype. Orders, subscriptions, deliveries, customers, reports,
and payment information use illustrative sample data and are not connected to
the backend. Menu items and categories are stored in this browser; selected
food images are stored in IndexedDB on this device. These local changes are
not shared with other users or devices. Other editable prototype state lasts
for the current app session.

`VITE_API_BASE_URL` is defined for future integration but is not used by the
current dashboard prototype.
